# 十轮小步优化：实验协议

开始前固定：每轮三个训练种子 7、17、27，从头各训练 32,768 环境步。第 1 轮仅把此前的 16,384 步加倍；后续单轮改变一个主要因素，根据验证结果选择保留或回退，明确记录父配置。不是十次延续同一检查点。

检查点选择保留此前规则：场景 100000–100003 的有效回合平均吞吐量。每轮训练后，在调参验证场景 410000–410007 上评估最佳与最后检查点及四种基线。选择后续父配置的主指标为三个训练种子的最佳检查点在这八个场景上统一 64 秒窗口吞吐量的均值，覆盖率、拒绝移动和波动作为辅助诊断。无效改动也记录，不事后删除。

最终测试预留场景 510000–510015，十轮完成前不读取其表现；十轮完成后统一测试全部版本及原始 16,384 步模型。不使用最终测试结果继续改模型。训练总预算为 983,040 环境步，不计前期实验和测试步数。

保持用户生成、信道、时限、航程与碰撞约束等物理任务固定，以便折线图可比较。动作参数化或观测表示可以改变，须保持真实用户状态不进入 Actor，不把真值服务指标注入奖励来悄悄改变信息条件。固定西侧起点的局限仍保留；本轮检验优化与表示能否改善这个已定义任务，不据此宣称跨布局泛化。

每轮开始前提交代码、配置与假设；完成后提交中文结果、完整逐更新日志（gzip 无损压缩）、每场景评估及来源哈希。检查点和逐帧大数组保存在本地 output/optimization；源码提交、完整配置和日志进入 Git。记录最佳与最后模型，避免用最佳检查点掩盖后期退化。最后绘制跨轮折线图和训练步数曲线，误差带使用三个训练种子均值之间的样本标准差，不冒充显著性检验。
