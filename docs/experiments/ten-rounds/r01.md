# 第 1 轮：固定时长的随机场景基准

按用户收窄后的任务，只保留地图边界、最低高度与机间防碰撞。地图、UAV 起点和聚类人群随机化，固定合法高度；取消航程预算，所有策略在相同 64 秒内提供服务。有限时域任务结束时不对价值自举。

本轮建立统一任务基准。网络、PPO 超参数、奖励权重沿用原始设置，三个种子从头各训练 32,768 步。后续九轮只改一个主要学习因素。此前固定布局及带航程预算的数据已单独保留，不计入此次十轮。

## 完整实验结果

训练源提交：`98f549af1a838c176c0a5cfab5d4c261fd07f4ef`。三个种子各 32,768 步，实际设备 MPS。本轮总墙钟耗时 5.44 分钟（含训练和调参评估）。

- **选中的最佳模型：**验证吞吐量 6.203 ± 0.895 Mbps；覆盖率 55.61% ± 10.41 个百分点；每回合拒绝移动 45.50 次。
- **训练结束模型：**验证吞吐量 6.158 ± 0.375 Mbps；覆盖率 58.85% ± 4.54 个百分点；每回合拒绝移动 86.00 次。

误差项为三个训练种子的场景均值之间的样本标准差。所有服务指标采用统一 64 秒窗口。

- 种子 7：选中 23552 步；调参验证最佳 7.235 Mbps，最后 5.962 Mbps。检查点选择集最初四次／最后四次评估均值 5.707／5.325 Mbps。
- 种子 17：选中 13312 步；调参验证最佳 5.739 Mbps，最后 5.921 Mbps。检查点选择集最初四次／最后四次评估均值 5.631／4.907 Mbps。
- 种子 27：选中 22528 步；调参验证最佳 5.634 Mbps，最后 6.590 Mbps。检查点选择集最初四次／最后四次评估均值 5.881／6.357 Mbps。

相同验证场景基线：waypoint 6.232 Mbps / 66.94%；greedy 8.045 Mbps / 70.54%；random 7.558 Mbps / 63.34%；stationary 7.342 Mbps / 61.84%。

## 决策

固定时长任务的基准验证吞吐量为 6.203 Mbps，最终模型 6.158 Mbps。最终模型拒绝移动事件较多，说明稳定部署仍有问题。后续按协议逐项优化，不根据此前被替代任务的结果跳过任何因素。
