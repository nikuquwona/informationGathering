# 第 1 轮：随机场景基准

本轮主要改动是任务采样：移除西侧固定起点，随机化矩形地图、三机起点、用户簇位置/形状/密度，并向 Actor 提供实际地图边界。无禁飞障碍；高度固定且校验最低高度。PPO、网络宽度和奖励权重沿用原实现，每种子训练 32,768 步。

这轮是新任务基准，不能与旧固定布局结果连线宣称提升。后续九轮只改学习因素，不再改变这套任务定义。朝东动作居中的建议已取消，从未应用。

假设：从随机起点训练可以暴露依靠固定方向的脆弱性；需要检查多种子服务表现、后半程趋势和最佳/最后模型差异。

## 完整实验结果

训练源提交：`f6395f8c8306e48d86d6c4fd8919ab142dc36e85`。三个种子各 32,768 步，实际设备 MPS。本轮总墙钟耗时 5.38 分钟（含训练和调参评估）。

- **选中的最佳模型：**验证吞吐量 6.320 ± 1.123 Mbps；覆盖率 53.90% ± 12.51 个百分点；每回合拒绝移动 39.96 次。
- **训练结束模型：**验证吞吐量 6.530 ± 0.834 Mbps；覆盖率 56.72% ± 9.48 个百分点；每回合拒绝移动 23.46 次。

误差项为三个训练种子的场景均值之间的样本标准差。所有服务指标采用统一 64 秒窗口。

- 种子 7：选中 19456 步；调参验证最佳 5.728 Mbps，最后 6.719 Mbps。检查点选择集最初四次／最后四次评估均值 5.622／6.899 Mbps。
- 种子 17：选中 32768 步；调参验证最佳 5.617 Mbps，最后 5.617 Mbps。检查点选择集最初四次／最后四次评估均值 5.759／6.459 Mbps。
- 种子 27：选中 9216 步；调参验证最佳 7.616 Mbps，最后 7.253 Mbps。检查点选择集最初四次／最后四次评估均值 6.156／6.335 Mbps。

相同验证场景基线：waypoint 5.103 Mbps / 54.05%；greedy 7.303 Mbps / 65.36%；random 7.558 Mbps / 63.34%；stationary 7.342 Mbps / 61.84%。

## 决策

作为随机任务基准保留。最终模型在独立调参验证集上略高于所选最佳模型，说明小规模检查点选择集存在波动；不能据此临时更改既定模型选择规则。下一轮只检查分组梯度裁剪。
