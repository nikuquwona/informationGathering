# 第 3 轮：增加每次更新的新轨迹批量

父配置：第 2 轮，由此前独立调参验证吞吐量均值选择。唯一主要因素：`training.rollout_steps` 从 `64` 改为 `256`。

假设：每次更新收集四倍连续数据，减小单回合梯度噪声；eval_every 同步改为 4，保持每 1024 步评估，训练总步数、每样本优化次数不变。

所有种子从头训练，各 32,768 步；任务分布、用户真值信息边界和安全约束不变。
