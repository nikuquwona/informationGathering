# 第 4 轮：延长优势递推的有效范围

父配置：第 2 轮，由此前独立调参验证吞吐量均值选择。唯一主要因素：`training.gae_lambda` 从 `0.95` 改为 `0.98`。

假设：提高 GAE 的 lambda，让延迟的感知收益传播得更远；代价是优势估计方差可能增加。

所有种子从头训练，各 32,768 步；任务分布、用户真值信息边界和安全约束不变。

训练源提交：`054cafec15c85ace1ac1836b57f634cc4f21109e`。三个种子各 32,768 步，实际设备 MPS。本轮总墙钟耗时 5.47 分钟（含训练和调参评估）。
